## 🔐 Overview

A beginner-friendly command-line login exercise that demonstrates username/password comparison and a limited number of login attempts using core Python control flow.

## ✨ Features

- Ask the user for login credentials.
- Allow a limited number of attempts (documented as three).
- Show feedback when credentials do not match.
- Practise loops, conditionals, and string comparison.

## 🧰 Concepts

- Variables and input/output
- `if / else` conditions
- `for` loops and loop control
- String comparison

## ▶️ Run

The repository includes a file named `python project`. Check its contents and run it with Python if it is a Python source file. Because the filename has no `.py` extension, renaming it to `login_system.py` would make the project easier to run and maintain.

```bash
python login_system.py
```

## ⚠️ Security Note

This is an educational CLI demonstration, not production authentication. It does not provide secure password hashing, account storage, rate limiting across sessions, or a real account-locking service. Never use plain-text password comparisons as the basis of a production login system.
